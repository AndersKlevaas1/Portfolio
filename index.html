Pågående hobbyprosjekt

GitHub Profile Analyzer

Et verktøy som analyserer GitHub-profiler og gir innsikt i bidrag, repositories og aktivitetsmønstre.

GitHub Profile Analyzer lar deg søke opp en hvilken som helst GitHub-bruker og få en visuell oversikt over profilen deres. Verktøyet henter data direkte fra GitHub sitt API og presenterer det på en ryddig og lettlest måte.

Prosjektet er bygget med vanilla JavaScript og hostet på Cloudflare Pages for rask global levering.
